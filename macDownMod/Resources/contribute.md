# 参与 macDownMod

项目存放于私有仓库 `git@github.com:teeSngRovn/macDownMod.git`。有访问权限的协作者可以在该仓库提交问题或改动。

开发前请阅读仓库中的 `README.zh-CN.md`、`BUILDING.zh-CN.md` 和 `CONTRIBUTING.md`。编译时使用 `macDownMod.xcworkspace` 与 `macDownMod` scheme；首次编译前需要运行 `bundle exec pod install` 和 `make -C Dependency/peg-markdown-highlight`。

版权与第三方组件许可保留在 `LICENSE/` 目录中。
